About The Project

AI-Powered Road Safety System

This project uses the YOLOv8 deep learning model to detect potholes from live camera input and estimate traffic risk in real time.

The system helps improve road safety by identifying damaged roads and providing intelligent traffic analysis and route recommendations.

  • Real-time pothole detection using YOLOv8
  • Traffic risk assessment (Low / Medium / High)
  • Alternate route recommendations
  • Road safety monitoring and reporting
